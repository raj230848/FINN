# FINN fonts

- **Inter**: body text, controls, research passages and tabular financial figures. [Fontsource](https://fontsource.org/fonts/inter).
- **Manrope**: headings and editorial hierarchy. [Fontsource](https://fontsource.org/fonts/manrope).

Original Latin variable WOFF2 files are bundled locally through `next/font/local`, with swap loading and system fallbacks. No runtime font CDN is required. Font weights remain variable rather than downloading separate files per weight.

Both unmodified font assets are distributed under SIL OFL 1.1. Their complete copyright/license notices are included beside the files. `sources.json` records the exact package versions, download origins, file sizes and SHA-256 hashes.
