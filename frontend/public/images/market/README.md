# FINN decorative market imagery

Created with the built-in image_gen tool for this project. These are decorative illustrations, not price data. Displayed as non-interactive, aria-hidden backgrounds. Opaque cards preserve reading contrast. WebP files were resized and compressed from the original generated PNGs; the artwork was not retouched.

- `stock-market-v1.webp` — 1400px wide stock-market illustration, 19,012 bytes.
- `global-markets-v1.webp` — 900px square global-market illustration, 25,682 bytes.
- `global-markets-light-v1.webp` — 1000px square champagne/bronze variant, 64,700 bytes.
- `stock-market-light-v1.webp` — 1400px wide light variant, 27,832 bytes.

The separate CSS sphere layer has been removed; the globe artwork is the primary background. Light mode uses these original light variants instead of faint filtering of the dark artwork.
